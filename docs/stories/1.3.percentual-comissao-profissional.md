## Story

**As a** dono do salão,
**I want** definir o percentual de comissão de cada profissional,
**so that** o sistema possa apurar quanto pagar sem cálculo manual.

## Acceptance Criteria

1. A tela de edição de Profissional (`/profissionais`) mostra e permite salvar o percentual de comissão (0 a 100, aceita decimais com vírgula ou ponto).
2. Salvar chama a server action `definirComissao`, que faz `upsert` da `ComissaoRegra` do profissional e espelha o valor em `Profissional.comissaoPercentual` na mesma operação.
3. Valor inválido (negativo, > 100, não numérico) retorna mensagem em pt-BR e não grava nada.
4. A lista de profissionais exibe o percentual atual de cada profissional.
5. Profissional sem regra definida aparece como `0%`.

## Dev Notes

### Contexto (fonte: `docs/architecture.md#2.1`, `#4`)

- `ComissaoRegra` é a tabela canônica (`profissionalId @unique`, `percentual` 0..100). Criada na Story 1.1.
- `Profissional.comissaoPercentual Float @default(0)` é **espelho denormalizado** só para exibição na
  lista; a Story 1.8 (relatório) lê de `ComissaoRegra`. Manter os dois em sincronia é responsabilidade
  desta action.
- Padrão de server action já existente: ver `src/app/agendamentos/actions.ts` (`criarAgendamento`
  retorna `{ ok, erro }`, usa `revalidatePath`). `src/app/profissionais/actions.ts` já tem
  `atualizarProfissional` (fire-and-forget). A nova action deve retornar resultado para exibir erro.
- `src/app/profissionais/page.tsx` é Server Component que lista profissionais; `ProfissionalRow.tsx`
  é o client component com o form de edição inline.

### Assunções explícitas

- Um profissional tem no máximo uma `ComissaoRegra` (escopo geral). Escopo por serviço = fase 2, fora daqui.
- Percentual é armazenado como número (ex.: `40` = 40%), não fração.

### Edge cases

- Campo vazio → tratar como `0` (não como erro), OU exigir preenchimento — **decisão: vazio = 0**.
- Profissional inexistente → `{ ok: false, erro: "Profissional não encontrado." }`.

### Testing

- **Sem teste automatizado** (a lógica de faixa é trivial; `comissao()` já é testada na 1.2).
- Manual:
  1. Editar Ana, definir `40,5` → salva, lista mostra `40,5%`.
  2. Editar com `-1` e com `120` → erro em pt-BR, valor não muda.
  3. Editar com vazio → vira `0%`.
  4. Conferir no Prisma Studio que `ComissaoRegra.percentual` e `Profissional.comissaoPercentual` batem.
