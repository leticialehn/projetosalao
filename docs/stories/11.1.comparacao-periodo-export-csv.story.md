## Story

**As a** dono do salão,
**I want** ver se o período atual está melhor ou pior que o anterior, e exportar os números,
**so that** eu acompanhe a tendência do negócio sem precisar montar a comparação na mão.

## Acceptance Criteria

1. Nova função pura `periodoAnterior(de: Date, ate: Date): { de: Date; ate: Date }` em
   `src/lib/datas.ts` calcula o período imediatamente anterior, de mesma duração em dias, ao período
   `[de, ate]` informado (ex.: período de 30 dias → os 30 dias imediatamente anteriores a `de`).
2. A tela `/comissoes` passa a mostrar, junto a cada um dos 3 cards de resumo já existentes (total de
   comissões, total cobrado, atendimentos concluídos), o valor do mesmo indicador no período anterior
   e a variação percentual entre os dois.
3. A lógica de busca dos atendimentos + agregação (`comissaoPorProfissionalComServico`) usada pela
   página é extraída para uma função compartilhada, reusada tanto pela página quanto pela exportação
   CSV (AC 4) — nenhuma lógica financeira duplicada entre os dois lugares.
4. Um link "Exportar CSV" na mesma tela baixa um arquivo CSV com os dados do período **atual**
   selecionado, nas mesmas colunas já exibidas na tabela (profissional, atendimentos, total cobrado,
   percentual, comissão, e a quebra por serviço quando houver regra específica).
5. A exportação (`GET /comissoes/export`) exige o mesmo papel (`PAPEL_DONO`) já exigido pela tela —
   mesma guarda, não uma nova.
6. Quando o período anterior não tem nenhum dado (ex.: salão começou a operar há pouco, total anterior
   = 0), a variação percentual **não** é calculada como número (evita divisão por zero) — a tela mostra
   um traço (`—`) no lugar.
7. `npm run test`, `npm run lint` e `npm run build` continuam verdes.

### Por que a exportação é uma rota separada (`/comissoes/export`), não uma action

Download de arquivo é uma navegação HTTP normal (o browser lida com `Content-Disposition: attachment`
sozinho quando é um link `<a href>` pra uma rota GET) — uma server action não tem como devolver um
arquivo pro browser baixar da mesma forma. Mesmo princípio já usado no projeto pra distinguir rota
(`/api/lembretes`, Epic 8) de action: cada uma serve o protocolo HTTP que faz sentido pro que ela faz.

  `src/lib/financeiro.test.ts` — não precisa ser retestada aqui.
- **Manual:** abrir `/comissoes` com dados de dois períodos consecutivos e conferir visualmente a
  comparação; clicar em "Exportar CSV" e abrir o arquivo baixado numa planilha pra conferir as colunas.
