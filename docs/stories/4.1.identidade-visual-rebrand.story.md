## Story

**As a** dono do salão,
**I want** que o sistema tenha uma identidade visual própria (nome, cores, tipografia) em vez do nome genérico "Projeto Salão" e da paleta padrão,
**so that** a ferramenta pareça um produto pronto e pessoal, não um projeto de desenvolvimento genérico.

## Acceptance Criteria

1. O nome exibido na marca (sidebar da área logada e cabeçalho da tela de login) é "Seu Salão", substituindo "Projeto Salão" em todos os pontos onde aparecia (`src/app/layout.tsx` — `metadata.title`, `src/app/(app)/layout.tsx`, `src/app/login/page.tsx`).
2. Nova paleta de cores (tons terracota/creme) aplicada via variáveis CSS em `:root` (`--bg`, `--card`, `--border`, `--text`, `--muted`, `--primary`, `--primary-dark`, `--danger`, `--ok`, `--shadow`), substituindo a paleta roxa anterior — sem quebrar nenhum uso existente dessas variáveis pelos componentes já implementados (badges de status de agendamento, botões, cards, diálogos).
3. Tipografia dedicada: fonte serifada para títulos/marca (Cormorant Garamond) e fonte de corpo (Jost), carregadas via `next/font/google` em `src/app/layout.tsx` e expostas como variáveis CSS (`--font-heading`, `--font-body`) consumidas em `globals.css`.
4. Efeito de capitular (`::first-letter` ampliado, com a fonte de título) aplicado consistentemente a: `h1`, `.brand`, links de navegação (`.nav a`) e nome do profissional na agenda (nova classe `.prof-nome`, aplicada em `src/app/(app)/page.tsx`).
5. Imagem de fundo (`public/bg-pattern.png`) aplicada ao `body` via CSS, mantendo o conteúdo legível (fundo fixo, `cover`, atrás do conteúdo).
6. Refinamentos visuais consistentes com a nova identidade: botões com cantos em pílula (`border-radius: 999px`), sombra sutil em `.card`/`dialog.dialogo` (via `--shadow`), estado de foco visível em `input`/`select`/`textarea`, micro-interação de clique em botões (`:active { transform: scale(.98) }`).
7. Nenhuma mudança de comportamento ou lógica de negócio — é uma story puramente visual/de estilo. Nenhuma regressão funcional nas telas existentes; `npm run test`, `npm run lint` e `npm run build` continuam verdes.
